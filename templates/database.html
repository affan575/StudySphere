MONGODBDatabase

users collection

Stores registered student account details.

  • _id — unique MongoDB document ID
  • name — student's full name
  • email — unique login email
  • passwordHash — securely hashed password
  • createdAt — account creation date

assignments collection

Stores each student's assignment information.

  • _id — unique assignment ID
  • title — assignment name
  • description — task details
  • course / priority / status — text values
  • dueDate and userId — date and owner reference
MongoDB stores documents · Mongoose defines schemas · Express handles CRUD APIs · React renders the data

VS Code demo implementation: This downloadable version uses Python Flask with a local SQLite database so it runs without installing MongoDB or Node.js. The diagram above explains the MERN architecture shown in the project design.
